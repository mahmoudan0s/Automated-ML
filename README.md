# Automated-ML
 ### Automated machine learning pipeline for data preprocessing, feature engineering, model training, evaluation, and model selection.
### [🚀 Live Demo](https://drive.google.com/file/d/1jjEjSmPfVxY0XFmCCwWhqyKEHbk-Kxcs/view?usp=sharing)
### Automated-ML simplifies the machine learning workflow by automating several steps of the model development process, from preparing the dataset to evaluating and selecting machine learning models.
The system supports three major machine learning tasks:

🎯 Classification
📈 Regression
🔵 Clustering

It automates the key stages of the machine learning workflow, including data preprocessing, missing-value handling, data balancing, bias-related preprocessing, feature engineering, model training, evaluation, comparison, and model selection.

The goal is to reduce repetitive preprocessing and model-development work while providing a streamlined workflow from raw data → preprocessing → model training → evaluation → selected model.

✨ Features
📊 Automated data preprocessing
⚙️ Feature engineering
🤖 Automated model training
📈 Model evaluation
🏆 Model comparison and selection
🔄 End-to-end machine learning pipeline

## Requirements

- Python 3.8 or later

#### Install Python using MiniConda
1) Download and install MiniConda from [here](https://docs.anaconda.com/free/miniconda/#quick-command-line-install)
2) Create a new environment using the following command:
```bash
$ conda create -n automated-ml python=3.11
```
3) Activate the environment:
```bash
$ conda activate automated-ml
```

### (Optional) Setup you command line interface for better readability

```bash
export PS1="\[\033[01;32m\]\u@\h:\w\n\[\033[00m\]\$ "
```

## Installation

### Install the required packages

```bash
$ pip install -r requirements.txt
```
